# My King Birthday Website

A mobile-friendly birthday tribute for SYED ALI ABBAS — My King.

## Files
- `index.html` — website content
- `style.css` — styling and layout
- `script.js` — letter, 28 candles and optional piano-like tones
- `assets/` — your original photo, character reference images and generated video clips

## Required asset filenames
Put these files inside `assets/` using exactly these names:
- `birthday-boy-original.jpg` — his original photo. Keep it unchanged.
- `prince.png` — prince character reference
- `princess.png` — princess character reference
- `01-hug.mp4`
- `02-horse-riding.mp4`
- `03-working-together.mp4`
- `04-badminton.mp4`
- `05-go-karting.mp4`
- `06-camping.mp4`
- `07-target-practice.mp4`

If you have not generated a clip yet, leave that video out; its card will simply be empty until you upload the matching MP4.

## Preview
Open `index.html` in a browser after keeping all files in the same folder structure.

## Publish with GitHub Pages
1. Open your repository.
2. Choose **Add file → Upload files**.
3. Upload/replace `index.html`, `style.css`, `script.js`, and `README.md`.
4. Upload the contents of this `assets` folder into the repository's existing `assets` folder.
5. Commit the changes to the `main` branch.
6. Open **Settings → Pages**.
7. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
8. Wait for deployment and open your GitHub Pages URL.

The page uses Google Fonts, so premium fonts require an internet connection. The piano-like background is generated by the browser and starts only after the visitor taps Play piano.
